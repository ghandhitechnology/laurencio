# Laurencio

Sync your AI coding agent configuration across devices, end to end encrypted.

Skills, instructions, agents, model preferences, MCP definitions, and optional memory follow your account. The server stores opaque blobs only.

Harnesses: Claude Code, Codex CLI, OpenCode.

Design: [DESIGN.md](DESIGN.md). Implementation plan: [plan/overview.md](plan/overview.md).

## Development

```
bun install
bun run check
bun run lint
bun test
```
